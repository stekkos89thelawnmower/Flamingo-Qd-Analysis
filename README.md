# Flamingo-Qd-Analysis
Reproducible analysis notebooks for differential measurements of Buchert's kinematical backreaction (Q_D) in FLAMINGO cosmological simulations. Includes paired comparisons between baryonic-physics variants, robustness tests, N-matching procedures, bootstrap/jackknife validation, and preregistered analyses.

Reproducible notebooks accompanying the technical reports:

1. Q_D measurement in FLAMINGO
2. Differential comparison of FLAMINGO variants
3. Robustness tests and preregistered validation
